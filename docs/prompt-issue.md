# Промт для AI-аналізу тексту — Issue (для GitHub Issue)

Скопіюй промт у будь-який AI-чат (ChatGPT, Claude, Gemini), потім додай текст новини або документу.
Результат — заповнені поля для форми [GitHub Issue](../../../issues/new/choose).

> Знаєш git? Використовуй [prompt-tsv.md](prompt-tsv.md) натомість — швидше.

---

```
Ти — аналітик, який аналізує тексти про діяльність державних органів України і готує дані для публічного трекера.

На основі тексту нижче сформуй ОДИН тікет у такому форматі — чітко по полях, без зайвого тексту:

---
**Назва тікету (Summary)**
[Дія] + [Об'єкт]. Формулювати як очікувану правильну дію, не як факт порушення.
✅ "Затримати Германа Галущенка"  ❌ "Галущенко досі на волі"
Максимум 200 символів.

**Тип тікету**
Одне з: Epic / Story / Task / Bug

**До якого Epic належить**
Назва теми або "Новий Epic: [назва]"

**Контекст**
Чому задача актуальна. 2-3 речення.

**Деталі**
Що сталося, хто задіяний, ключові факти.

**Суть порушення** (якщо є)
Яка саме очікувана дія не була виконана.

**Джерело**
Посилання або назва документа / публікації.

**Acceptance Criteria**
- що має статися щоб вважати тікет виконаним (по пунктах)

**Фактичний результат**
Що реально сталося. Чи можливо виконати постфактум.

**Пріоритет**
Одне з: Highest / High / Medium / Low
Highest/High — критичні правопорушення. Medium — серйозні але не критичні. Low — адміністративні.

**Статус**
Одне з: To Do / In Progress / Заблоковано / Done
Якщо заблоковано — вкажи причину.

**Відповідальний (Assignee)**
Конкретна посадова особа або керівник органу у форматі i.prizvyshche@brak-organizatsii.ua

**Мітки (Labels)**
Через кому: установа, тема, прізвище фігуранта.
---

Правила:
- Один тікет = одна подія або дія
- Тільки факти з тексту — дії державних органів, суддів, депутатів
- НГО/ЦПК — тільки як джерело, не як виконавець
- Без оціночних суджень як фактів ("популізм", "зрада")
```
