## Через форму

Найпростіший спосіб — не потребує знання git або TSV формату.

**1** → Перейди на вкладку [Issues](../../../issues) → натисни **New Issue**

**2** → Обери шаблон **"Запропонувати новий тікет"**

**3** → Заповни всі обовʼязкові поля:

| Поле | Що писати |
|------|-----------|
| **Назва тікету** | Коротко і конкретно. Формат: `[Дія] + [Об'єкт]` → "Затримати Германа Галущенка" |
| **Тип тікету** | `Epic` — велика тема. `Story` — конкретна подія. `Task` — організаційна дія |
| **До якого Epic** | Назва існуючого Epic або пропозиція нового |
| **Контекст** | Що сталося, хто задіяний, чому важливо |
| **Джерело** | Посилання або назва документа. Без джерела — не приймається |
| **Acceptance Criteria** | Що має статися, щоб вважати проблему вирішеною |
| **Пріоритет** | Див. [правила пріоритетів](field-reference.md#пріоритет) |

**4** → Натисни **Submit new issue**

**5** → Мейнтейнер перевірить і конвертує у TSV

## Через Pull Request

Для тих хто знає git і хоче одразу додати тікет у правильному форматі.

**1** → Зроби fork репо

**2** → Скопіюй шаблон:
```bash
cp tickets/_template.tsv tickets/назва-теми.tsv
```

**3** → Відкрий файл і додай рядки. Кожен рядок — один тікет:
```
Work type	Summary	Work item ID	Parent	Description	Priority	Labels	Assignee
Epic	Назва теми	1		Опис Epic	High	label1	
Story	Конкретна подія	2	1	* Контекст: ...\n* Джерело: ...\n* AC: ...	High	label1	
```

**4** → Запусти валідацію локально:
```bash
python scripts/validate.py --file tickets/назва-теми.tsv
```

**5** → Відкрий Pull Request з описом що додаєш і чому

> [!NOTE]
> Валідація запускається автоматично при відкритті PR. Якщо є помилки — GitHub покаже що саме виправити.

## Правила хорошого тікету

**Summary — конкретний і дієвий**
```
❌  Проблема з ДБР
❌  Розслідування корупції
✅  ДБР не відкрило розслідування щодо витоку фото Шабуніна
✅  Затримати Германа Галущенка та вручити підозру
```

**Один тікет = одна подія або дія**
```
❌  Галущенко затриманий і взятий під варту і призначена застава
✅  Затримання Галущенка та вручення підозри        ← тікет 1
✅  Обрання запобіжного заходу — застава 200 млн грн ← тікет 2
```

**Description — три обовʼязкові блоки**
```
* Контекст: реєстрація фонду на Ангільї у 2021 році; відмивання коштів через офшори
* Джерело: НАБУ, прес-реліз від 12.07.2025 — https://nabu.gov.ua/...
* Acceptance Criteria: Галущенко затриманий; підозра офіційно вручена
```

**Тільки дії державних органів**
- ✅ ДБР, НАБУ, САП, суди, Рада, Кабмін, міністерства
- ❌ НГО та громадські організації — вказуй лише як джерело у Description

## Типові помилки

| Помилка | Як виправити |
|---------|-------------|
| Summary без дії: "Справа Галущенка" | Додай дієслово: "Затримати Галущенка" |
| Немає джерела | Знайди офіційну заяву або публікацію |
| Один тікет охоплює кілька подій | Розбий на окремі тікети |
| Epic замість Story | Epic — тема/серія. Story — конкретна подія |
| Дія НГО як основна | НГО → тільки в Description як джерело |
| Summary > 200 символів | Скороти, деталі перенеси в Description |
