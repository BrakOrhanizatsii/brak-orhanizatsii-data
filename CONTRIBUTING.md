# Contributing

## Два способи додати тікет

| | Через Issue (форма) | Через Pull Request |
|--|--------------------|--------------------|
| **Для кого** | Всі | Ті хто знає git |
| **Що робити** | Заповнити форму | Редагувати TSV напряму |
| **Хто конвертує** | Мейнтейнер | Ти сам |
| **Інструкція** | [docs/how-to-add-ticket.md](docs/how-to-add-ticket.md#через-форму) | [docs/how-to-add-ticket.md](docs/how-to-add-ticket.md#через-pull-request) |

## Правила для PR

- Один PR = одна тема або одна подія
- Запусти `python scripts/validate.py --file tickets/твій-файл.tsv` перед пушем
- Назва коміту: `feat: додати тікети про [тема]`

## Чого не робити

- Тікети без джерел
- Дії НГО як основна тема тікету (тільки як джерело)
- Дублікати існуючих тікетів
- Summary довше 200 символів або без конкретної дії
